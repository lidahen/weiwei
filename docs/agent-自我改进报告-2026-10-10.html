已采纳的工作流原则（写入 SKILL.md，长期生效）

  1. 最简优先：能 workflow 不 agent；按成本类选用 Anthropic 五模式。
  2. 评测先行：增加 agent 复杂度之前先建固定测试集与失败分类。
  3. trace 留痕：重要运行记录 trace，失败归因到 prompt / 工具 / 检索 / 模型 / 状态管理。
  4. 机制分层：loop 属于 agent、机制属于 harness——加能力改外层，不动核心循环。
  5. 安全边界：工具 annotation 不可信；危险动作保留人工确认。
  6. 时效铁律：6 个月以上教程先核对官方 changelog；评估 harness 而非模型。
