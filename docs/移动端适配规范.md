# 移动端适配规范（第三期产物）

> 2026-09-25 ｜ 适用 `ui/` 全部 C 端页面；管理后台（System/Monitor/Human/Log/Tool）默认不做移动适配，ProTable 横向滚动即可读，访问时提示用桌面端。

## 一、断点约定（唯一基准）

| 层级 | 断点 | 用途 |
|---|---|---|
| 移动 | `< 768px`（CSS 写 `max-width: 767px`） | 全站统一移动断点。JS 用 `useIsMobile()`（内部同源），CSS 用 `tokens.mq.mobile` |
| 平板 | `< 900px`（个别页面 899，如首页 hero 堆叠） | 仅平板过渡布局，不承载业务差异 |
| 桌面 | `>= 1024px`（如 Login 桌面版式） | 桌面增强，不作为业务分叉点 |

❌ 禁止新引入 899/1024 作为移动/桌面业务分叉；移动行为分叉一律走 768。

## 二、JS 分支与 CSS 分支怎么选

- **布局结构不同**（双栏→单栏、Table→卡片列表）：用 `useIsMobile()` 渲染两套 JSX。
- **仅样式差异**（间距/字号/显隐）：用 antd-style 的 `[mq.mobile]: {...]`，或 global.less 辅助类，**不要**为此多渲染一套 DOM。

## 三、global.less 辅助类（已就绪，直接用）

| 类名 | 作用 |
|---|---|
| `.tw-desktop-only` | 移动端隐藏（Header 问号/语言/用户名文字在用） |
| `.tw-mobile-only` | 桌面端隐藏 |
| `.tw-safe-bottom` | 单点安全区：`padding-bottom: env(safe-area-inset-bottom)` |
| `.tw-sticky-footer-bar` | 底部粘性操作条（毛玻璃+上边框+安全区），详情/表单页底部按钮统一容器 |

## 四、组件替换对照表（移动端）

| 桌面组件 | 移动端做法 |
|---|---|
| `Row/Col` 固定 span | Col 补 `xs={24}`；或 isMobile 时改纵向 flex 堆叠（参考 `Runner/Hall.tsx` 筛选区） |
| `Table` | 移动端换卡片式列表（Map 渲染 Card），或 `expandable` 收纳次要列；管理后台 Table 例外（横滚兜底） |
| `Descriptions` | `column={isMobile ? 1 : n}` |
| `Select` 下拉 | 加 `style={{ width: '100%' }}`（移动端整行）；选项多的筛选建议弹层内单选列表 |
| `Modal` 表单 | 移动端 `width="94%"`；复杂表单考虑 `Drawer placement="bottom"` |
| `Segmented/Tag 组` | 移动端 `block` 撑满，严禁与同级元素叠放 |
| 右对齐操作按钮区 | 移动端放 `.tw-sticky-footer-bar`，按钮 `block` 等宽 |
| 固定宽度（400~1200px） | `maxWidth: 原值 + '100%'` |
| List grid 固定 column | `column: isMobile ? 1 : n`（参考 `UserAddress.tsx`） |
| 触控目标 | 可点元素 ≥44×44（热区不足的补 padding） |

## 五、硬性红线

1. 文字不得互相叠压/被容器裁切：可收缩文本必须 `minWidth:0 + overflow:hidden + textOverflow:ellipsis`，不可收缩的（城市/时间等）设 `flexShrink:0` 且**总数不得超行宽**。
2. 移动端禁止出现横向滚动条（管理后台 Table 除外）。
3. 底部固定元素必须含 `env(safe-area-inset-bottom)`。
4. `100vh` 一律用 `100dvh` + `@supports` 回退（移动端地址栏抖动）。
5. 不为移动端单独起接口/改业务参数；适配只发生在视图层。

## 六、验证流程（每次改动后）

1. `cd ui && npx tsc --noEmit`：错误数必须保持 16（存量），新增即修。
2. Chrome DevTools iPhone 仿真（390×844）过一遍改动页。
3. 涉及抽屉/遮罩/滚动的改动**必须真机过一遍**（桌面仿真测不出，历史上"真机白底截断/遮罩丢失"两例均因此漏网）。
4. 回归基线截图：`logs/mobile-audit/`。
